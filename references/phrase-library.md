# 句式与选题指南

由15篇真实案例归纳、改写。句式帮助打开话题，不能保证流量；原作者的经历不能当作船员自己的事实。

## 常用句式：问大家本来就关心的事

| 角度 | 可借的句式 | 参考 |
|---|---|---|
| 求工具 | 大家都用什么AI做【用途】啊？／【某类人】现在都用什么AI【做事】？ | I01、I03 |
| 求效果 | 有什么AI能做出【一眼能懂的效果】？／求一款【关键体验】的【工具】 | I03、I11、I14 |
| 晒成果 | 好奇大家用AI做了什么【成果】？／想看看大家把AI用到了什么程度 | I08、I09、I10 |
| 找灵感 | 交出你用AI做的【作品】／大家用AI做过什么好用又好玩的小东西？ | I08、I12 |
| 问花费 | 做【用途】，你们一个月都充多少钱？／【用途】有必要专门开AI会员吗？ | I02 |
| 问门槛 | 【工具】真的那么难用吗？／明明【可核实的优势】，为什么还有人不选？ | I06 |
| 选工具、聊体验 | 【A】和【B】，你们会选哪个？／【工具】有人用吗？／【A】真的不如【B】吗？ | I13、I15 |
| 求信息源 | 想学【方向】，大家都在看谁？／除了【已知来源】，还有没有推荐？ | I04 |
| 真实求助 | 有人遇到过【真实卡点】吗？／求助！【实际问题】怎么解决？ | I07 |
| 讨论观察 | 我关注的【对象】最近【真实观察】，大家也注意到了吗？ | I05 |

这些不是逐字引文。没有亲身经历也可以问大家用什么、花多少、做出了什么，不必先写一段“我最近……”；想聊付费也不必假装付过钱。不要把“最近大家都不用某工具了”当作已经成立的事实。

## 封面直白，正文才补条件

| 容易写成问卷的问法 | 更适合先打开话题的写法 | 正文可补 |
|---|---|---|
| AI写完周报，你们最常改什么？ | 大家都用什么AI做PPT啊？ | 有没有生成后还能自己改字、换图的？用过的推荐一下？ |
| 用AI后你的内容产出效率提升多少？ | 好奇大家用AI做出了什么好东西？ | 网页、小工具、视频都想看看，能解决实际问题的更好。 |
| 你选择视频模型的核心评价指标是什么？ | 做AI视频，你们最舍得给哪个工具充钱？ | 好奇大家最后留下的是哪一个，也想听听值在哪。 |
| 大模型代码修改后你如何验收？ | 好奇大家用AI搓出了什么小工具？ | 自己还在用的那种，想看看普通人能做到什么程度。 |

这是选题取舍示例，不是说两个问题含义相同，也不是禁止专业讨论。用户明确要收集流程反馈时，可保留专业问法；面向起号的公开互动，先考虑容易懂、容易接话的题。

## 同一个句式，扩展不同内容

“大家都用什么AI做……啊？”可以扩展到PPT、产品展示视频、插画、会议记录等；“好奇大家用AI做了什么……”可以征集短片、小工具、海报等。固定开头可以保留，差异落在账号确实要聊的用途、成果或体验标准上。

知道方向就能先写：

- AI办公：PPT、表格、会议、文档；不是默认都问周报怎么修改。
- AI视频：工具、成片效果、角色一致性、生成成本；不是默认都问工作流步骤。
- AI作图：想要的风格、实际作品、修图效果、选择工具。
- Vibe Coding：普通人做出了什么、在用什么工具、能否做出能用的东西。

这些只是候选。结合目标人群或用户指定用途选题；有自己参考、素材和已发内容时优先使用。不要每次给所有账号发同一套示例，也别只靠随机换称呼来假装个性化。一次生成里避免同题的多种改写；换一个大家关心的对象可以成为新题，不需要硬凑每篇都换两三个维度。

## 几句话就够

封面一句话抛问题；正文1—3句补标准、邀请晒成果或解释好奇的点。求推荐时让人能报工具名，晒成果时让人知道晒什么，讨论选择时给别人留下表达空间。不要追问一串“为什么、怎么做、用了几步、提升多少”，也不用每条都加“欢迎评论区分享”。

I02、I05、I08、I13等原文较长，本Skill只借提问结构，不照搬长度。I07不照搬辱骂；I13、I15不证明工具优劣；I15没有独立正文，不能把封面当作原文正文。
