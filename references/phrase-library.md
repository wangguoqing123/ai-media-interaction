# 问法与差异化指南

下列问法由内置15篇案例归纳、改写，编号对应案例索引；不是逐字抄录，也不是爆款或推荐机制的保证。原作者的经历和观点不能作为船员自己的事实。

## 先决定想让别人回答什么

| 讨论目的 | 可参考的问法 | 案例 |
|---|---|---|
| 晒成果 | 好奇大家用【工具】做了什么【具体成果】？／想看看大家把【AI】用到了什么程度 | I08、I09、I10 |
| 找灵感 | 我已经做了【自己的真实成果】，大家还做过什么？ | I12 |
| 求工具 | 有什么AI能做出【目标效果】？／求一款【明确体验标准】的【工具】／做【任务】的朋友都用什么？ | I01、I03、I11、I14 |
| 求信息源 | 除了【已知来源】，还推荐哪些【符合要求的来源】？ | I04 |
| 问成本、方案 | 做【任务】，你们通常选什么【方案／档位】？最看重什么？ | I02 |
| 讨论门槛 | 【工具】真的那么难用吗？／明明【实际存在的优势】，为什么有人不选？ | I06 |
| 交流体验 | 有人用【工具】做【任务】吗？／我觉得【一句真实感受】，你们呢？／【A】真的不如【B】吗？ | I13、I15 |
| 请教卡点 | 让AI做【任务】，却出现【实际问题】，大家怎么处理？ | I07 |
| 讨论观察 | 我关注的【具体对象】最近【真实观察】，大家也注意到了吗？ | I05 |

想问花费但没有付费经历时，改成“准备做【任务】，想问问大家一般花多少”，不要写“我已经烧了几千”。没有行业观察时，不选择“最近都断更了”这种现象断言。I07只借具体卡点的叙述方式，不照搬辱骂；I13和I15只提供体验表达的参考，不证明工具强弱。

## 差异来自具体问题

用户只给“AI视频”，容易产生泛泛的工具推荐题。拿到“给家里的猫做15秒短片”，才有作品形式、角色一致性和试错成本等具体讨论点。

可从用户确实提供的材料中选择：

- **任务与对象**：宠物短片、商品图、会议记录、课程PPT、小店排班工具。
- **目标效果**：角色长相一致、减少塑料感、回复自然、成品可以实际使用。
- **条件与卡点**：现有素材、不会的步骤、可接受的时间或预算；没提供的个人条件不能编。
- **期待回应**：晒成果、报工具、解释选择、给操作方法、交流成本、补充信息源。

同一任务可以连续讨论，但每篇的核心问题和期待回答应不同。换了工具名而答案仍是同一批工具清单，视为重复；同一个开头问成片、过程和成本，可以是不同问题。先决定讨论点，再选择固定句式、变体或自由问法，不按表格顺序自动生成。

使用船员自己的任务和对象。本指南中的宠物短片、会议记录、小店排班只是解释方式，不是所有账号的默认选题；不能把同一套示例换个称呼就发给每位船员。

## 正文只补交流所需的信息

- 求推荐：说明需要完成的任务或效果，给别人一个推荐标准。
- 晒成果：说明想看哪种成果，让别人知道分享什么。
- 经验与卡点：用真实情况说明问题，把解释和建议留给评论者。
- 体验讨论：保留自己的真实感受并交代场景，允许不同意见，不伪造主流评价。

不要求每篇都含个人经历。公开征集可以直接问，用户不必假装已经做过。I02、I05、I08、I13等原文较长，只借其提问结构；本Skill的生成结果仍以1—3句正文为准。I15没有单独文字正文，不能把其封面文字误记为原帖正文。

## 一次交付前检查

把每篇暂时概括成“想问的具体问题 → 希望收到的回答”。若两篇几乎相同，合并或重写其中一篇；不靠修改措辞掩盖重复。检查与用户已发内容的关系，并确认所有个人事实均有输入依据。检查只用于改稿，默认不把这张内部对照表交给船员。
